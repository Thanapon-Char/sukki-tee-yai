# Go Web App

A clean, responsive single-page web app built with HTML5 and CSS3.

## Live Demo
Check out the live page here: [https://thanapon-char.github.io/go-web-app/](https://thanapon-char.github.io/go-web-app/)

## Features
- Modern UI with frosted glassmorphism styling
- Responsive grid layout
- Interactive start button

## Getting Started
Open [index.html](index.html) directly in any modern web browser or clone the repository:

```bash
git clone https://github.com/Thanapon-Char/go-web-app.git
```
